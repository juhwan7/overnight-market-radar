# 운영·예약·비용·장애

## 실행 경로

GitHub Actions: 수집 → 공개 원자료 필드·시각 검증 → 표준화 → 독립 규칙 분석 → 스냅샷/당시 판단 저장 → React 웹 빌드 → Pages 업로드 → 배포 → 공개 HTML/데이터/manifest 해시·commit·시각 검증.

예약은 UTC `3,13,23,33,43,53 * * * *`. 정시나 10분 간격을 보장하지 않습니다. 시작시각을 10분 슬롯에 대입해 지난 실행부터 빈 슬롯 수를 기록합니다. 슬롯 지연은 예정 스케줄 이벤트의 정확한 전달시각이 없어 추정입니다. 과거 데이터 조회 어댑터를 통해 검증한 값만 공백 보완 가능하며 현재 값을 과거 슬롯에 복사하지 않습니다.

공개 저장소 표준 GitHub 러너·Pages는 공식 무료 범위. [공식 비용](https://docs.github.com/en/billing/concepts/product-billing/github-actions). 하루 144, 30일 4320회. 3분 실행 가정 12960분/월. 기본 LLM API 0달러·유료 데이터 별도. Pages 업로드 1일 보존, 정상 대시보드 약 3MB 가정 하루 432MB 아티팩트 규모. 저장량·처리시간은 측정 후 예산 수정해야 하며 저장소 commit 이력은 별도 누적합니다. `.private`는 아티팩트·공개 Git에 포함하지 않습니다.

장중 10분 목표와 일/주/月 통계의 실제 수신 주기는 다릅니다. 각 실행의 캐시는 로컬 TTL을 사용하지만 GitHub 새 러너에는 이전 원자료 캐시가 없어 기본 공개 공급자 요청이 반복됩니다. 현재 실제 13회 이하 요청/실행 규모, 4320회 시 월 약 56160 HTTP 요청 상한 가정. 공급자 정책과 실제 수신 지연을 확인하고 호출량을 줄일 전용 지속 캐시가 후속 작업입니다. KIS 토큰은 `.private`로만 보관하며 public Actions cache에 넣지 않습니다.

## 배포 검증

`python -m radar.package`가 `radar-data.json`, `radar-manifest.json`, `.nojekyll`을 생성합니다. `radar.verify_url`은 5회 이내 재시도, 각 대기 30초 이내. 공개 URL 스냅샷 ID·원본 데이터 SHA256·HTML SHA256·코드 commit·자료 생성시각을 비교합니다. 브라우저 렌더링·모바일 검증은 별도이며 HTTP 검증만으로 시각 검증 완료라고 하지 않습니다.

단일 concurrency group은 실행·최종 쓰기·배포 충돌을 줄입니다. 일부 예약 대기는 플랫폼에 의해 취소될 수 있으며 놓친 슬롯은 기록합니다. 원격 main이 동시에 바뀌면 자동 강제 push·재배포를 하지 않고 실패합니다. 운영 장애는 다음 실행에서만 다시 수집됩니다. 저장 실패·빌드 실패·배포 실패는 Actions 작업 실패로 기록되고 마지막 Pages는 남습니다. 개별 데이터 실패는 마지막 정상 값과 원래 기준시각을 유지하며 낮은 위험으로 처리하지 않습니다.

## ChatGPT 예약

현재 환경에서 예약 도구와 GitHub 읽기 연결은 확인했습니다. 저장소 생성·Pages 관리 도구가 없고 새 저장소의 쓰기와 운영 URL을 아직 검증하지 못했으므로 **운영 예약 등록 및 첫 실행은 대기**입니다. 클라우드 예약에 로컬 PC나 이 임시 작업 폴더가 계속 존재한다고 가정하지 않습니다.

연결 후 등록할 1시간 주기 점검은 GitHub의 최신 `src/data.json`, 워크플로우 실패, 공개 URL을 읽고 공식 발표의 심층 해석·누락·새로운 위험·개선 요청을 검증합니다. 사용 가능한 도구로 쓰기가 실제 확인되면 `research/latest.json`에 구조화 근거를 저장하고 당시 후보를 수정하지 않습니다. AI가 실패해도 규칙 수집·페이지는 계속 갱신됩니다. ChatGPT 구독과 LLM API 비용은 별개입니다. 예약 첫 실행 요청 성공과 실제 완료·쓰기 성공을 구분해야 합니다.

## 장애 이력

2026-10-01 초기 검증 중 FOMC 달력의 중첩 `<a>` 제목 파싱 및 SEC 관찰목록 설정 이름 오류를 발견·수정했습니다. 수정 후 다섯 공개 공급자 수신 성공. Playwright 설치는 브라우저 ZIP이 정상 파일로 내려오지 않아 실패했습니다. 다른 Chromium 패키지로 로컬 브라우저 검증을 완료했습니다. 9탭·실제 차트·상세 펼침·로컬 저장·390px 모바일 가로 넘침 없음·페이지 오류 없음 확인. 실제 GitHub 워크플로우와 공개 URL은 아직 검증되지 않았습니다.

GitHub 모든 스케줄이 중단되면 같은 스케줄 안의 감시 코드가 복구한다고 주장하지 않습니다. [공식 예약 제한](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule): 부하 지연·작업 누락·공개 저장소 60일 무활동 비활성화. 독립 감시·외부 스케줄러는 별도 계정·예산이 필요한 제안입니다.
